# 🔵 Ball Arena

**Ball Arena** — небольшая аркадная 2D-игра на Python с использованием библиотеки Pygame. Игрок управляет шариком, который сражается с компьютерным противником на арене.

Главная цель — победить противника, используя физику столкновений и специальные способности.

## 🎮 Основные возможности

- Битва игрока против компьютерного противника.
- Выбор цвета своего шарика перед началом матча.
- Выбор одной из 7 уникальных способностей.
- Случайный выбор цвета и способности компьютером.
- Физика движения шариков.
- Отскоки от границ арены.
- Столкновения между шариками с нанесением урона.
- Система здоровья (HP).
- Перезарядка способностей.
- Визуальные эффекты и анимации.
- Экран победы и поражения.
- Возможность поставить игру на паузу.

## ✨ Способности

В игре доступно 7 способностей:

| Способность | Описание |
|---|---|
| 🚀 Турбо | Увеличивает скорость шарика на 2,5 секунды. |
| 💥 Тяжёлый удар | Увеличивает урон от столкновений в 2 раза. |
| 🛡️ Энергощит | Защищает от урона в течение 3 секунд. |
| 🔮 Энергоснаряд | Выпускает снаряд, наносящий 22 единицы урона. |
| 💣 Мина | Создаёт ловушку, наносящую 26 единиц урона противнику. |
| ❤️ Регенерация | Восстанавливает 22 единицы здоровья. |
| ❄️ Заморозка | Замедляет противника на 2,5 секунды. |

У каждой способности есть собственное время перезарядки.

| Клавиша | Действие |

| A / ← | Толчок влево |

## ⚙️ Технологии

- **Python 3.13** — основной язык программирования.
- **Pygame** — игровое окно, графика, обработка событий и игровой цикл.
- **Math** — математические вычисления и физика движения.
- **Random** — случайные значения и выбор параметров противника.
- **Dataclasses** — структуры данных для игровых эффектов.

## 🚀 Установка и запуск

### 1. Установка Python

Установите Python 3.13 или совместимую версию.

### 2. Установка Pygame

Откройте терминал VS Code и выполните:

```bash
python -m pip install pygame
```

### 3. Запуск игры

Перейдите в папку проекта и выполните:

```bash
python main.py
```

## ⚔️ Правила игры

1. Перед началом матча игрок выбирает цвет и способность.
2. Компьютер случайным образом выбирает собственные параметры.
3. После начала матча оба шарика автоматически движутся по арене.
4. При столкновении шарики получают урон.
5. Игрок может использовать свою способность, когда она готова.
6. Побеждает тот, кто первым лишит противника всех очков здоровья.
